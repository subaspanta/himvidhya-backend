REAL-TIME MESSAGE FLOW:

┌────────────┐  Socket.IO    ┌────────────┐  Socket.IO    ┌────────────┐
│  CLIENT A  │◄─────────────→│   SERVER   │◄─────────────→│  CLIENT B  │
└────────────┘               └────────────┘               └────────────┘
                                    │
                                    │ Save to MongoDB
                                    ▼
                            ┌───────────────┐
                            │    Message    │
                            │   Broadcast   │
                            │  to Room      │
                            └───────────────┘

1. Client A connects with JWT token → Socket.IO authenticates
2. Client A joins room: 'conversation-ID'
3. Client A emits: 'send-message' { conversationId, content }
4. Server handler:
   - Saves message to MongoDB
   - Updates conversation's lastMessage
   - Broadcasts 'receive-message' to room
5. All clients in room (A & B) receive message instantly
6. UI updates without page reload
